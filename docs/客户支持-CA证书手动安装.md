# 客户支持：CA 证书手动安装（Windows）

> 用途：客户在软件里点【安装/检测】没成功时的兜底方案。
> 版本：适用于 sphdl v2.2.18 及以后（更早版本请先升级，旧版有窗口闪退问题）。
> 最后更新：2026-10-25

---

## 一、给客户的说明（可直接复制发送）

```
【Windows 装证书 · 手动版】

软件里点【安装/检测】没成功的话，按下面手动装一次，1 分钟搞定：

第 0 步：先生成证书
  打开软件 → 点【启动嗅探】→ 等 5 秒 → 点【停止】
  （证书在第一次启动嗅探时才生成，没启动过就没有这个文件）

第 1 步：打开证书管理器
  按键盘 Win + R，输入 certmgr.msc，回车

第 2 步：找到正确的位置
  左边窗口依次展开：
  「证书 - 当前用户」→「受信任的根证书颁发机构」→ 点一下「证书」
  ⚠️ 注意是「受信任的根证书颁发机构」，不是「个人」

第 3 步：导入
  在右边空白处右键 → 所有任务 → 导入

第 4 步：选文件
  点「下一步」→ 点「浏览」→ 把下面这行整个复制到地址栏，回车：
  %USERPROFILE%\.mitmproxy\mitmproxy-ca-cert.cer
  选中文件 → 打开 → 下一步

第 5 步：完成
  一路「下一步」→ 若弹出「安全警告」，点【是】
  看到「导入成功」就好

第 6 步：验证
  回到软件 → 点【安装/检测】→ 状态应变成「已安装 ✓」
```

---

## 二、两个最容易出错的地方（必须一起发）

| 错误 | 后果 | 怎么防 |
|---|---|---|
| 装到了「个人」而不是「受信任的根证书颁发机构」 | 不生效，嗅探抓不到视频 | 第 2 步截图确认位置 |
| 第 5 步安全警告点了「否」 | 导入成功但不被信任 | 强调点【是】 |

**如果 `%USERPROFILE%\.mitmproxy\` 打不开** → 证书还没生成 → 回第 0 步。

## 三、给客服/自己看的原理（不用发客户）

### 证书文件说明（`%USERPROFILE%\.mitmproxy\`）

| 文件 | 大小 | 能不能导入 | 说明 |
|---|---|---|---|
| `mitmproxy-ca-cert.cer` | 1172 B | ✅ **推荐** | 不含私钥，双击即弹导入向导 |
| `mitmproxy-ca-cert.pem` | 1172 B | ✅ 可 | 内容同上，只是扩展名不同 |
| `mitmproxy-ca-cert.p12` | 1035 B | ⚠️ 要密码 | 一般不用 |
| `mitmproxy-ca.pem` | 2847 B | ❌ **禁止** | **含私钥**，certutil / 导入向导会拒绝，也不该外传 |

### 为什么必须装到「受信任的根证书颁发机构」

工具用 mitmproxy 做本地 HTTPS 解密。系统只有在**根证书**存储里
找到并信任这张 CA，才会接受它为视频号域名签发的临时证书。
装到「个人」存储只代表"我有这张证书"，不代表"我信任它签发的证书"，
所以嗅探会失败。

### 为什么「装到当前用户」就够（不需要管理员）

`certmgr.msc` 默认打开的是**当前用户**存储，写入不需要管理员权限。
软件 v2.2.18 起自动安装也是装到 `-user Root`，同样不需要提权
——这正是我们彻底摆脱"UAC 弹窗 / 命令窗口"的原因。

### 卸载/重置（客户要重装时）

```cmd
certutil -delstore -user Root <证书序列号>
```
或在 `certmgr.msc` → 受信任的根证书颁发机构 → 找到 `mitmproxy` → 右键删除。
删掉后重新启动嗅探会自动再生成一张新的。

## 四、历史事故（别再犯）

**2026-10-25**：3 个客户报障「装证书时命令窗口闪退」，其中 **2 位退款**。

根因：`install-cert.bat` 被存成 **LF 换行**，cmd 解析失败
→ `cd /d "%~dp0"` 报「系统找不到指定的路径」→ 脚本 **0.03 秒退出**
→ 客户看到窗口一闪就没，完全不知道发生了什么。

影响范围：`dist/` 下 **v2.2.2 ~ v2.2.16 全部 13 个已发 zip**。

**修复（v2.2.17 / v2.2.18）**：
1. 两个 bat 转 CRLF + `.gitattributes` 锁死 `*.bat eol=crlf`
2. `release.py` 打包自检：bat 非全 CRLF → 拒绝出包
3. **v2.2.18 彻底不启动控制台进程**：改为进程内 `certutil`
   带 `CREATE_NO_WINDOW`，成功/失败都走 messagebox，
   失败时自动把证书路径复制到剪贴板

**教训**：面向客户的辅助脚本，**"窗口一闪而过"本身就是交付缺陷**，
不管底层原因是什么。能用无窗口方式做的，就不要启动控制台。
