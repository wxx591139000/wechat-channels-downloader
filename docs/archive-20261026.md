## 二、核心变更

### 2.1 CA 证书安装（v2.2.17 → v2.2.23）

**事故**：3 个客户报障「装证书时命令窗口闪退」，**其中 2 位退款**。

**三层根因**（逐层挖出来的）：

| 层 | 根因 | 表现 |
|---|---|---|
| 1 | `.bat` 是 LF 换行（不是 CRLF） | cmd 解析失败，0.03 秒退出 |
| 2 | 写根证书库必须过 Windows 确认框 | `CREATE_NO_WINDOW` 下框弹不出来 → 「操作已被用户取消」 |
| 3 | 微信在**进程启动时**读证书信任 | 装完不重启微信，视频号抓不到 |

**影响范围**：`dist/` 下 v2.2.2 ~ v2.2.16 **全部 13 个已发 zip** 都有第 1 层问题。

**最终方案**：
```
点【安装/检测】
  → 自绘预告框（22pt 红色加粗）：「Windows 会弹安全警告，请点【是】」
  → 后台 PowerShell + .NET X509Store 写 Root（零命令行窗口）
  → 主动把 Windows 确认框调到最前
  → 写入生效立即返回
  → 成功框（绿色）+ 红色 22pt「完全退出微信，再重新登录」
     + 黄底强调「不做这一步，播放视频号仍然抓不到！」
     + 「帮我退出微信」按钮（taskkill）
```

**实测完整首装**：1.2 秒弹出安全警告 → 点「是」→ 证书入库 → `uninstall` 还原成功。

### 2.2 「抓不到视频」看门狗（v2.2.23）

客户原话：「避免抓取不到，也没任何提示……避免静默失败」。

`addon` 埋 4 个计数器，GUI 每 5 秒判定（3 分钟冷却 + 25 秒宽限）：

| 现象 | 结论 | 给客户的指引 |
|---|---|---|
| TLS 失败 > 0 | 证书没生效 | 微信没重启 / 没装对 / 杀软拦截 |
| 页面活动 ≥3 但抓到 0 | 钩子没挂上 | **页面在启动嗅探前就打开了** |
| 已抓到 > 0 | 正常 | 不打扰 |
| 无微信流量 | 不判定 | 不提示 |

### 2.3 授权码吊销（v2.3.0 / v2.3.1）

**改造前实测**：作废对已激活客户端**完全无效**——继续下载、无提示、连转卖到新电脑都挡不住。
原因：`license.py` 零网络调用，码里无"作废"字段，服务器无下发通道。

**方案 B 云端吊销名单**：
```
GET https://license.zhuanlu.xyz/api/revoked   →  [{code, reason}]
客户端 启动+每 30 分钟 → 命中则降档 + 停下载 + 弹窗
```

**★★ 客户红线（v2.3.1）：失联时绝不降档 ★★**

只有**能证明**作废才降档：
- 本次联网成功且明确列出 → 降档
- 断网但 6 小时内的成功响应里明确列出 → 降档
- 404 / 500 / HTML / `ok:false` / 畸形 / 超时 / 无缓存 / 缓存过期 / 无 `verified` 标记 → **一律不降档**
- 服务器恢复该码 → 下次校验**自动恢复档位**（可逆）

## 十、本轮最值得记的三条

**① 首装路径必须实测，不能只测「已安装」**

v2.2.17 修完 LF 我以为搞定了，直到客户说"我试下新版"我才删掉自己的证书测首装，
这才发现 `certutil` 返回「操作已被用户取消」——**这个 bug 已存在好几版**，
因为每次测试都走"已安装"短路分支。典型自证循环。

**② 「窗口一闪而过」本身就是交付缺陷**

不管底层是换行符、杀软、UAC 还是路径。能用无窗口方式做的，就不要启动控制台。

**③ 静默失败比报错更致命**

客户最痛的一句话是「避免抓取不到，也没任何提示」。
报错至少知道怎么回事，静默失败只会让客户觉得"软件坏了"→ 退款。
