# 发码台账（作者侧追溯）— 使用说明

> 面向：软件作者本人（你）
> 位置：`sphdl/tools/ledger.py` + `license_tool.py ledger` 子命令
> 台账文件：`E:\myHermesWorkSpace\_archives\keys\licenses.jsonl`（**仓库外，不入库**）
> ⚠️ 含客户联系方式（PII）→ **绝不入库、绝不进交付包、绝不随软件分发**
>
> **v2.0.19 更新**：新增「公众号文章视频」功能位 —— 一个软件卖两次。
> 基础码只能下视频号，`--feature all` 的码才能下公众号文章视频。

---

## 0. 一分钟速查（最常用）

```bash
cd E:/myHermesWorkSpace/wechat-channels-downloader/sphdl

# 只卖视频号（老行为，ver=1 码，35 字符）
python tools/license_tool.py gen 20000 --customer "闲鱼昵称" \
    --contact "闲鱼:xxx888" --channel "闲鱼" --price "199"

# 视频号 + 公众号文章视频（新功能，ver=2 码，38 字符）
python tools/license_tool.py gen 20000 --feature all --customer "闲鱼昵称" \
    --contact "闲鱼:xxx888" --channel "闲鱼" --price "299"
```

| 需求 | 加什么参数 | 码型 | 长度 |
|---|---|---|---|
| 只下视频号 | （不加 `--feature`） | ver=1 | 35 字符 |
| 只下公众号视频 | `--feature mp` | ver=2 | 38 字符 |
| 两个都要 | `--feature all` | ver=2 | 38 字符 |

> ⚠️ `--feature mp`（只有公众号）在实际使用中比较怪 —— 客户打开软件发现视频号功能没授权。
> **推荐直接用 `--feature all`**，把公众号作为"升级包"卖给已有客户。
> 工具会自动给 ver=2 码补上视频号基础位，所以 `--feature mp` 实际生成的是「公众号+视频号」。

## 为什么要有这个

设备绑定防的是「同一个码被多台机器用」；
**如果对方直接把整个 zip + 码转发出去，绑定也拦不住。**

这时唯一的追责手段就是台账 —— 你手里有一张「码 → 客户」的对应表。

| 场景 | 台账的作用 |
|---|---|
| 闲鱼上出现别人在卖你的软件 | 查码 → 知道是**哪个买家**流出去的 → 举报/停止售后 |
| 同一个人反复来要码 | 看出他在批量倒卖 → 拒绝 |
| 有人声称"我是老客户要换绑" | 查台账核对身份 → 防冒名 |
| 想知道什么档位卖得好 | 顺带得到经营数据 |

一句话：**设备绑定是「锁」，台账是「眼睛」。只有锁没眼睛，转卖者换个说法你也不知道。**

## 日常用法（发码时自动登记）

```bash
cd E:/myHermesWorkSpace/wechat-channels-downloader/sphdl

# 发一个旗舰版码给闲鱼买家（自动登记台账）
python tools/license_tool.py gen 20000 \
    --customer "闲鱼昵称" \
    --contact "闲鱼:xxx888" \
    --channel "闲鱼" \
    --price "199" \
    --note "旗舰版永久"
```

输出示例：
```
# 客户/备注: 旗舰版永久
SPHDL-0420-XXXX-XXXX-XXXX-XXXX-XXXX      ← 把这个发给客户
📒 已登记台账 1 条 → E:\myHermesWorkSpace\_archives\keys\licenses.jsonl
（档位: 旗舰版（2 万条）｜有效期: 永久）
```

**参数说明**

| 参数 | 说明 | 建议 |
|---|---|---|
| `--customer` | 客户名/昵称 | ★ 必填，否则出事查不到是谁 |
| `--contact` | 联系方式 | ★ 建议填，如 `闲鱼:xxx888` |
| `--channel` | 销售渠道 | `闲鱼` / `微信` / `朋友介绍` |
| `--price` | 成交价 | 便于统计 |
| `--note` | 备注 | 自由文本 |
| `--no-ledger` | 不登记 | 仅测试时用 |

> 不填 `--customer`/`--note` 时，工具会提醒你「否则出事查不到是谁」。

## 查台账

```bash
# ① 列出全部记录
python tools/license_tool.py ledger list

# ② ★溯源：闲鱼上看到某个码，查是谁流出的
python tools/license_tool.py ledger find SPHDL-0420-XXXX-XXXX-XXXX-XXXX-XXXX

# ③ 按设备码查（识别「同一台机器被多个客户申请」= 批量转卖）
python tools/license_tool.py ledger device A3F8-91C2-B7E4-5D9A

# ④ 统计（销量/档位/渠道分布）
python tools/license_tool.py ledger stats
```

`find` 支持**容错**：小写、漏横杠、多半角都能查到。

`stats` 会**自动标出重复设备码**：
```
⚠️ 重复设备码（同机多码，疑似转卖）：{'A3F8-...': 2}
```

## 台账文件长这样

```jsonl
{"code":"SPHDL-0420-...","tier":20000,"tier_label":"旗舰版（2 万条）","days":0,"customer":"张三","contact":"闲鱼:zhangsan88","device":"","price":"199","note":"旗舰版永久","channel":"闲鱼","issued":"2026-10-16 22:16:43"}
```

- **append-only**：每次发码追加一行，永不覆盖历史
- 可以直接用记事本/Excel 打开查看，也可以用 `ledger list` 看
- 手工编辑坏了也不要紧：坏行会被跳过并告警，好行照常读

## 注意事项

1. **台账文件在 git 仓库外** —— 天然不入库，含 PII 也不会误提交。
2. **不要放进交付包** —— 客户包里只有软件和授权码，没有台账。
3. **建议备份** —— 与密钥备份同目录，一起备份到 U盘/网盘。
4. **写入失败不会阻断发码** —— 但会打印告警并提示应记录的内容，需手工补录（避免"以为记了其实没记"）。
5. 可用环境变量 `SPHDL_LEDGER` 指定其他台账路径（默认路径见文件开头）。

## 公众号文章视频功能码（v2.0.19 新增）

### 商业模式：同一个 exe 卖两次

```
客户买基础版 → 你给他一个普通码 → 只能下视频号
客户加钱买公众号功能 → 你给他一个 --feature all 的码 → 视频号 + 公众号文章视频
```

**不需要重新发软件包** —— 同一个 exe，只换码。客户粘新码立即解锁，不用重启。

### 发码

```bash
cd E:/myHermesWorkSpace/wechat-channels-downloader/sphdl

# 旗舰版 + 视频号 + 公众号文章视频
python tools/license_tool.py gen 20000 --feature all \
    --customer "闲鱼昵称" --contact "闲鱼:xxx888" \
    --channel "闲鱼" --price "299" --note "含公众号功能"
```

输出：
```
SPHDL-0820-00RY-7JEY-WHR0-31R8-9GTF-30        ← 发给客户
📒 已登记台账 1 条 → E:\myHermesWorkSpace\_archives\keys\licenses.jsonl
（档位: 旗舰版（2 万条）｜功能: 视频号下载、公众号文章视频下载｜有效期: 永久｜码型: ver=2）
```

### 功能位对照

| 参数 | 含义 | 备注 |
|---|---|---|
| （不加） | 仅视频号 | ver=1 老码，35 字符，**与 v2.0.18 行为完全一致** |
| `--feature vc` | 仅视频号 | ver=2 码，38 字符（功能上等同不加，但码型不同） |
| `--feature mp` | 公众号文章视频 | **工具会自动补视频号基础位**，实际= `all` |
| `--feature all` | 视频号 + 公众号 | ★推荐用于卖"完整版" |

可以叠加：`--feature vc --feature mp` 等同 `--feature all`。

### 给已有客户升级（最常见的场景）

```bash
# 老客户已经用普通码，现在想加公众号功能 → 直接发个新码，他粘进去即可
python tools/license_tool.py gen 20000 --feature all \
    --customer "老客户张三" --channel "微信" --price "100" \
    --note "老客户升级公众号功能"
```

**客户操作**：软件里点「🔑 授权管理」→ 粘贴新码 → 点「激活」。**立即生效，无需重启。**

> 提醒：粘新码后档位也会跟着新码走。如果老客户是标准版想只加公众号功能，
> 用同样档位发即可（如 `gen 1000 --feature all`）。

### 客户界面怎么看他有没有授权

软件 →「🔑 授权管理」→ 顶部会显示：

```
当前档位：旗舰版（2 万条）        功能：视频号✓ 公众号视频✓
```

未授权时显示 `公众号视频✗`（红色）。激活日志也会打：
```
🔑 授权成功：档位 旗舰版（2 万条），永久有效｜功能：视频号下载、公众号文章视频下载
```

### 公众号功能怎么用（你可以转告客户）

1. 拿到公众号文章链接（形如 `https://mp.weixin.qq.com/s/xxxxx`）
2. 软件里选「公众号视频」入口 → 粘贴链接
3. 软件解析出文章里所有视频（一篇文章可能有多个）
4. 选清晰度（标清/高清/超清/蓝光）→ 下载

**限制（如实告知客户）**：
- 只支持**公众号文章**里的视频，不支持视频号（那是另一个入口）
- 链接有**时效性**（微信的 `auth_key` 会过期），拿到链接要尽快下载
- 加密的/付费的文章若读不到内容，就解析不到视频

## 与设备绑定版的关系
台账**现在就可用**（本次已上线），设备绑定版（ver=2）尚未实施。

设备绑定实施后：
- `gen --device <设备码>` 会把设备码也记进台账
- `ledger stats` 能直接发现「同一设备被多人申请」
- `ledger device <设备码>` 可排查冒名换绑请求

两件事独立：**台账先上零风险，绑定后上再加锁。**
