## 四、本轮最重要的三个教训

### ① 字段名不能猜，必须看真实 payload（P25）

视频统计数找了 **5 轮**：猜 30+ 别名 → 加诊断证否 → 转储完整 body → 才对。
第一轮就该存完整响应体。

### ② 静默吞异常是连环 bug 的元凶（P26/P27）

- `except: pass` 吞掉 `addon` 未创建的 AttributeError → 连续两版"文件存错目录"
- `__file__` 在打包后失效 → 调试开关永远读不到 → 差点得出"小程序做不了"的**错误结论**

### ③ 测试假绿三次（P33）

| 现象 | 真因 |
|---|---|
| 勾选框 20/20 过，页面没 ✓ | CSS 抽空串，页面裸奔 |
| 后台 22/22 过，页面 500 | 只测函数，没测页面能否打开 |
| 滚轮 29/29 过，客户零效果 | 假 `scroll_fn`，测不出滚轮有没有落到窗口 |

**对策已固化**：样式测试断言 CSS 长度；后台必跑路由冒烟；
系统交互必做真实端到端并读真实状态。
