# 新平台接入检查单（sphdl）

> 用途：每加一条平台线（抖音 → B 站 → 小鹅通 → ClassIn …）之前/之后照着走一遍。
> 来源：`docs/PITFALLS.md` P1–P69 里**跨平台会重复犯**的那些，去掉视频号专属项。
> 最后更新：2026-11-13（v3.4.4 去重口径，补 2.7 / 6.8 两条闸门）

---

## 0. 一趟走完的顺序

```
探明链路（真请求，别照抄文章）
  → 写 xxxx.py（纯函数优先）
  → 写 xxxx_store.py + xxxx_ui.py
  → 授权接进 5 条产品表
  → 跑「接入检查单」（本文件）
  → 本地 HTTP 断点续传回归
  → 打包（--clean）→ 真跑 exe → 截图读像素
  → 部署发码后台 → 生产发码 → 客户端校验
  → 升版 + CHANGELOG + tag
```

---

## 1. 授权（最容易"漏一处静默失效"，P59 / P65）

| # | 检查项 | 命令 / 判据 |
|---|---|---|
| 1.1 | 产品号只加一个字节，老码零影响 | 老码 `verify_code` 仍返回原 product/tier |
| 1.2 | 进 `PRODUCTS_NO_TIER` | 漏了 → `make_code` 抛「不支持的档位」 |
| 1.3 | 进 `PRODUCT_LABELS` | 漏了 → 码**静默失效** |
| 1.4 | `label_of_product` 有展示名 | 否则台账/界面显示 `None` |
| 1.5 | **不要**再手写产品元组 | `grep -n "for p in (lic.PRODUCT_"` 应为 0 |
| 1.6 | 后台 `PRODUCT_LABEL` / `NO_TIER_LABEL` / 下拉 / 复制文案 | 与客户端**集合相等** |
| 1.7 | 后台发码 → 客户端认（**每个产品号都过一遍**） | 不许两边各自 round-trip 自证 |
| 1.8 | 互斥性：新码不当老产品、老码不含新产品 | 严格互斥，不是位掩码 |
| 1.9 | 本平台的按钮/面板有 🔒 未授权态 + 购买引导 | 未授权点了要有反应 |
| 1.10 | 只买新产品的客户，顶部通用展示**不许**显示「未授权」 | 遍历 `PRODUCT_LABELS` |

## 2. 链路探明（P16 / P25 / P57 / P61 / P62）

| # | 检查项 | 判据 |
|---|---|---|
| 2.1 | 先抓**完整响应体**再看结构，不猜字段名 | 存一份原始 JSON 到本地 |
| 2.2 | 社区文章的结论必须自己验一遍 | 端点/Referer/UA 不同，结论就不同 |
| 2.3 | `drm` / `encrypted` 这类字段名不等于协议事实 | 拿到 m3u8 还是 mpd？key 能不能取？ |
| 2.4 | 混淆/编码串先把**尾部**打出来 | `=` 之后可能是噪声（P61） |
| 2.5 | 单连接慢 ≠ 平台限速 | 先并发 8 路再下结论（P63） |
| 2.6 | 并行要节流 + 拟人间隔 | 别把对方 CDN 打急 |
| 2.7 | **去重键标识的是「业务对象」还是「某一路文件」？**（P69） | 多清晰度/多签名会让 `md5sum`、`encfilekey`、URL 全变；必须找到跨报文恒定的对象 ID，并用别名索引（oid/md5/nonce/url 任一命中）判重。**绝不按标题合并** |

## 3. 下载与断点续传（P28 / P50 / P51 / P52）

| # | 检查项 | 判据 |
|---|---|---|
| 3.1 | 临时文件名由**内容标识**决定，**不带时间戳** | 两次调用路径必须相同 |
| 3.2 | 启动时读磁盘上已有断点 | 首帧进度从断点值起，不是 0 |
| 3.3 | 用户点停止**不删**断点 | 保留 `.part` / `.parts/` |
| 3.4 | 分片原子落盘：写 `.tmp` → `os.replace` | 否则断电留"有内容但不完整"的片 |
| 3.5 | 「已完成」判据不是"文件在不在/够不够大" | 分片看原子性，整文件看 Range 收尾 |
| 3.6 | 成品认多种后缀（`.mp4` / `.ts`） | 否则没 ffmpeg 的客户反复重下（P66②）|
| 3.7 | 地址过期要**重取一次**再判死 | 403/404/416 ≠ 下不了 |
| 3.8 | 下载成功 ≠ 文件可用 | ffprobe 验流构成（有画面有声音）|

## 4. 界面（P38 / P41 / P42 / P47 / P54 / P64）

| # | 检查项 | 判据 |
|---|---|---|
| 4.1 | 平台按钮**单独一行**，别挤进已满的行 | 截图确认 4 个按钮都在（不是被静默挤出）|
| 4.2 | 底部固定区用 `side="bottom"` 先占位，表格最后 pack | 窗口变矮也不许把状态条挤没 |
| 4.3 | Treeview `heading(anchor=)` 与 `column(anchor=)` **成对写** | 别指望默认值 |
| 4.4 | 外部标题进表格前 `one_line()` 压平 | 带 `\n` 会被行高切半行 |
| 4.5 | 后台线程只碰纯 Python 数据 | Tk 变量在主线程先取好 |
| 4.6 | 下载线程 `try/except` + `finally` 补发 `*_all_done` | 否则界面永久卡「下载中」|
| 4.7 | ✕ 用 `withdraw()` 不 `destroy()` | 任务还在跑，隐藏即可 |
| 4.8 | 一个窗口只留**一条**标题栏 | 带系统边框就别再自绘一套按钮 |
| 4.9 | 让窗口真的打开一次并截图**读像素** | 不能只看代码"写了" |

## 5. 打包与发版（P36 / P49）

| # | 检查项 | 判据 |
|---|---|---|
| 5.1 | `--clean` 必加，且清 `__pycache__` | 不加会打出旧代码 |
| 5.2 | 真跑 exe 看窗口，`--selftest` 不算 | selftest 不启动 GUI |
| 5.3 | 新窗口模块加进 selftest 的 import 检查 | 漏收 → 点按钮才崩 |
| 5.4 | 截图按**标题**找窗口，不按 pid | 程序会提权重启 |
| 5.5 | 截图按 `GetWindowRect` 建位图再裁客户区 | 带边框的窗口会丢底部 31px |
| 5.6 | 截图/自检用 `SPHDL_DATA_DIR` 指临时目录 | **别污染真实 config/records** |
| 5.7 | 三处版本号一致（`__init__` / README / CHANGELOG） | 不一致视为发版失败 |
| 5.8 | `git add` 只加明确路径 | 别用 `-A`（历史事故：17 个 zip 入库）|

## 6. 测试（P33 / P53 / P60）

| # | 检查项 | 判据 |
|---|---|---|
| 6.1 | 先落 `config.json` 再 import gui | `CONFIG_FILE` 是模块级常量 |
| 6.2 | 写完密钥要清 `lic._secret_cache` | 失败缓存会把偶发变永久 |
| 6.3 | UI 状态按**真实事件分发路径**验 | 别只从队列取一条就断言 |
| 6.4 | 样式断言用 `style.lookup()` 查实际值 | 不是断言"我调用了 configure" |
| 6.5 | 每个用例独立输出目录 | 别让上一条产物混进 `glob` |
| 6.6 | 断点续传要**跨进程/新服务器**验 | 同进程连调两次证明不了重启能续 |
| 6.7 | 红了先问"是产品坏了还是测试自己错" | 但确认后**仍然要修测试** |
| 6.8 | 改去重口径要同时验四个入口：捕获 / 候选缓存与锚点 / 删记录释放 / 跨会话索引 | 还要测**反例**：同名但对象 ID 不同必须仍保留多行（P69） |

## 7. ClassIn 待办（还没开始写代码）

到 2026-11-10 为止，ClassIn **只有线索、没有结论**，缺的是**一节真实课程回放**。
拿到链接后先按 §2 走，重点确认四件事：

1. 回放是 HLS(m3u8) 还是 mp4 直链，还是私有协议/分片加密；
2. 是否需要登录态 Cookie / 签名参数（`sign` / `t` / `us`），有没有时效；
3. 密钥是随 m3u8 下发还是单独接口（对照 P62：别看到 drm 就判死）；
4. 单连接与 8 路并发的实测吞吐（对照 P63：别用小样本判限速）。

拿到这四条再决定是否值得做产品线；**没实测前不要承诺"能下"**。
