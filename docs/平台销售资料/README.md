# 平台销售资料

> **规则：各平台的出售信息必须放在本目录下对应的平台子目录里，不许直接堆在 `docs/` 根目录。**

## 目录结构

```
平台销售资料/
├── 闲鱼/
│   ├── 文案-公众号版.md          ← 公众号视频产品的闲鱼文案
│   ├── 配图-公众号版/            ← 该文案配套的 3 张图
│   │   ├── 01_封面.png
│   │   ├── 02_三步操作.png
│   │   └── 03_功能清单.png
│   └── 配图-通用/                ← 通用销售素材（多产品可复用）
│       ├── idlefish_main.png     封面图（历史版）
│       ├── detail_long.png       长图详情页
│       ├── poster.html           海报 HTML 源（可改）
│       └── poster.png            海报导出图
├── 小红书/
│   └── xhs_cover.png             封面（1080×1440）
└── _共用素材/
    └── ui_effect.png             软件界面截图（任何平台都能用）
```

## 命名约定

| 位置 | 命名 |
|---|---|
| 平台根目录 | `文案-<产品线>.md` |
| 配图子目录 | `配图-<产品线>/` 或 `配图-通用/` |
| 图内文件 | `NN_<用途>.png`（NN 是展示顺序） |

**产品线取值**：`公众号版` / `视频号版` / `通用`

## 新增平台时

1. 在 `平台销售资料/` 下建平台目录（如 `淘宝/`、`拼多多/`）
2. 平台目录内再按产品线分子目录
3. 该平台的专属规范写进 `平台行为差异.md`（见下）

## 平台行为差异（重要）

不同平台的规则不一样，写文案时要注意：

| 平台 | 关键差异 |
|---|---|
| **闲鱼** | 详情页写价、私聊谈；首图决定点击率；禁止在图上写联系方式 |
| **小红书** | 偏种草，不能硬广；标题党不吃香，要真实体验感 |
| 待补充 | — |

## 配图生成脚本

| 产品线 | 脚本位置 |
|---|---|
| 公众号版（闲鱼 3 张） | `sphdl/tools/make_xianyu_images.py` |
| 通用海报 | `平台销售资料/闲鱼/配图-通用/make_promo.py` |

改文案/配色后重跑脚本即可，不要手改 PNG。

## 素材复用原则

- `_共用素材/` 放**任何平台都能用**的东西（软件界面截图等）
- 平台专属图放该平台目录，**不要放 `_共用素材/`**
- 一张图如果两个平台都要用，就复制两份到各自目录（便于各自独立改）
