- product 1 视频号（需证书）/ 2 公众号 / 3 抖音（免证书）

## 7. 常用操作要点（跨版本仍然有效）

### 7.1 CA 证书安装（客户退款过 2 单，务必保持现在的实现）

- **不要再用批处理装证书**：`install-cert.bat` 曾因 LF 换行导致 cmd 解析失败、
  窗口闪退，3 个客户报障、2 个退款。
- 现在做法：进程内 `certutil`（`CREATE_NO_WINDOW`，零命令行窗口）+
  主动把 Windows「安全警告」框调到最前。
- **装完必须提示客户「完全退出微信再登录」**：微信在进程启动时读证书信任链，
  不重启抓不到。成功提示框里有一条 22pt 红色加粗的这条要求。
- 兜底：`CA证书手动安装SOP.pdf` 随包在 zip 顶层（`docs/` 下有 docx 源文件）。

### 7.2 抓不到视频时的看门狗（silent-failure-prevention）

- 每 5 秒自检：微信域名 TLS 失败 / 页面活动但零捕获 → 弹诊断框给客户具体操作。
- 冷却 3 分钟防刷屏，启动后 25 秒宽限。

### 7.3 评论抓取

- 按**结构**识别（昵称类键 + 内容类键），不依赖固定 `cmdName`（微信常改名）。
- 嵌套回复递归渲染；归属靠三重防护（nonce / payload ID 反查 / 全局 cid 唯一）。

### 7.4 授权码吊销（方案 B）

- 客户端定期拉 `https://license.zhuanlu.xyz/api/revoked`（30 分钟）。
- **只有能证明作废才降档**：服务器失联、404、畸形响应 → 一律不降档。
- 缓存 6 小时内有效；恢复后自动恢复档位。

### 7.5 抖音批量下载

- **不需要装证书**（自己开 Edge 读页面响应，不做 MITM）。
- 打包依赖：`微信视频号下载器.spec` 里 `collect_all('playwright')`。
- 每版必跑 `exe --selftest-douyin`（验证 PyInstaller 没打坏 playwright driver）。
- 限流五层对策见 `sphdl/douyin.py` 顶部注释。
