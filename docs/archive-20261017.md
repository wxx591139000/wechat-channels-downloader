## 二、防盗体系（本次归档重点）

> **完整方案：`防盗体系-VPS完整方案.md`（22KB，11 章）**

### 2.1 四层防护

```
第 1 层  授权码自身      HMAC-SHA256 + 码内嵌档位/产品/台数/绑定
第 2 层  设备绑定        ver=3，4 项取 2，死绑单机（换硬盘/重装不失效）
第 3 层  台数上限        ver=4，激活时服务器统计执行
第 4 层  追溯            水印(截图带设备码) + 激活上报 + 台账
```

**前 3 层是"锁"，第 4 层是"眼睛"。锁能被撬，眼睛摘不掉。**
实际运营中第 4 层价值往往大于前三层——因为它让你知道**是谁**。

### 2.2 四种码型（并存）

| 码型 | 长度 | 语义 |
|---|---|---|
| ver=1 | 35 | 老码，仅视频号，不绑机不限台（**已发出的 4 个老码永远有效**） |
| ver=2 | 38 | 含产品线，不绑机不限台 |
| ver=3 | 45 | 死绑单机（4 项取 2） |
| ver=4 | 40 | 限 N 台（服务器统计） |

### 2.3 VPS 部署（零影响纪律）

| 服务 | 端口 | 归属 |
|---|---|---|
| bot（转录机器人） | 3001/3002/3003 | **原有业务，勿碰** |
| cloudflared | 隧道 | 原有 |
| **sphdl-license** | **3010** | 本项目新增（license.zhuanlu.xyz） |
| **sphdl-admin** | **3011** | 本项目新增（sphdl-admin.zhuanlu.xyz） |

- 新目录 + 新端口 + 独立 systemd + 纯标准库（不动 pip 环境）
- 密钥 `/opt/sphdl-admin/env`（600）
- 每次部署后 diff 端口快照，确认只多出新端口

### 2.4 诚实的边界声明

| 攻击者 | 能否防住 |
|---|---|
| 普通客户转卖 | ✅ 能防 |
| 二手商帮买家远程激活 | ⚠️ 部分 |
| 会逆向的人 | ❌ 防不住（PyInstaller 字节码） |
| 教买家断网激活 | ⚠️ 部分（断网放行是取舍） |

> 没有任何技术手段能完全防住盗版。目标应是"让盗版成本略高于正版价格"
> 和"保护付费用户不被打扰"。

⚠️ **过度反盗版（频繁弹窗、强制联网、锁死）造成的差评与退款损失，
常超过它挽回的盗版损失。** IDM 是反面教材。

## 四、v2.1.x 修掉的 11 个真实 bug

**全部由客户实测暴露，全部已修并加了回归测试。**

| # | bug | 根因 |
|---|---|---|
| 1 | 粘公众号码后列表上限变 0 | `_apply_tier(info["tier"])` 直接用了 tier=0 |
| 2 | 激活新产品顶掉旧产品授权 | 只存单个 `license_code` |
| 3 | 清除授权后授权仍有效 | `_clear_license()` 没清新的 dict 字段 |
| 4 | 界面卡死 | 水印 `after` 定时器指数增殖（6 处 return 各排任务） |
| 5 | 水印闪烁可被抓拍 | `withdraw → deiconify` 有隐藏空档 |
| 6 | 水印看不到 | 浮层没 `-topmost`，被主窗盖住 |
| 7 | 水印挡别的软件 | topmost 无遮挡判断（且 `GetForegroundWindow` 是过修） |
| 8 | 启动卡 4 秒 | 硬件指纹采集 4 项各等 wmic 超时（3682ms） |
| 9 | CA 证书装不上 | 证书要嗅探生成，但装证书挡住了嗅探启动（死循环） |
| 10 | 启动失败无提示 | 只写日志区，用户只看到"点了没反应" |
| 11 | **改档位把限台数变不限** | 台数下拉预选错 + 后端没沿用旧值 |

**共同特征：都是"在开发机上正常、在客户机器上才暴露"。**
