# sphdl 使用 SOP（图文版文字稿）

> 适用：Windows 10/11 + 桌面版微信（web 视频号嗅探）。
> 全程只需两个文件：`run.bat` 和（首次）`install-cert.bat`。

---

## 第 0 步（一次性）：安装 CA 证书

工具通过本地代理解密 HTTPS 流量，Windows 必须先信任 mitmproxy 的根证书。
`install-cert.bat` 已升级为**全自动**：双击后自动导入到「受信任的根证书颁发机构」
（当前用户存储，无需管理员），窗口会停住显示结果：

- 看到 `[OK] ... already installed` → 已装好，直接下一步
- 看到 `[SUCCESS] Certificate installed` → 刚装好，直接下一步
- 看到 `[ERROR]/[WARN]` → 按窗口里的提示处理（若弹过 UAC 选框，点「是」后重跑一次）

> 本机（2026-08-24）证书**已安装并验证通过**，此步可跳过；
> 任何时候重新双击 `install-cert.bat` 都可复查（已装则秒过，窗口不会闪退）。
> 打开主窗口看右上角 CA 证书 是否显示「已安装 ✓」也可以。

> 证书只存在于你这台电脑的"当前用户"存储，不影响别的机器；
> 想删除：`Win+R` → `certmgr.msc` → 受信任的根证书颁发机构 → 删除 mitmproxy。
>
> ⚠️ 排错备注（2026-08-24 实测）：导入必须用纯证书文件
> `mitmproxy-ca-cert.pem`（`mitmproxy-ca.pem` 含私钥，certutil 会报
> CRYPT_E_NO_MATCH）；且本机 `certutil -store root` 不带 `-user` 会列错存储，
> 验证必须用 `certutil -store -user root`。bat 必须保持纯 ASCII + CRLF 编码，
> 否则中文注释会被 cmd 截断导致窗口闪退。

## 第 1 步：启动工具

双击 `sphdl\run.bat`
（首次会自动创建虚拟环境并安装依赖，约 1–3 分钟；之后启动 <3 秒）

## 第 2 步：开始嗅探

主窗口点 **▶ 启动嗅探**
- 勾选"自动设置系统代理"（默认勾）：全机流量临时走本地代理，停止时自动恢复
- 状态栏变绿「嗅探: 运行中 127.0.0.1:8899」= 就绪
- 状态栏「钩子: Xs前」实时反映视频号页面钩子活性（v1.2.1）：数字小=链路健康；
  显示「X分钟前 ⚠」或「无 ⚠」= 钩子丢失，按排错表处理
- 引擎区「⚙ 自动下载（捕获即入队）」（v1.2.2）：默认不勾=手动点选下载；
  勾选=新捕获自动下载（状态记忆）

## 第 3 步：播放视频

打开微信 → **视频号** → 随便点开一个视频让它播放。
（web 视频号页面首次加载时会自动注入嗅探钩子，日志区会显示「JS 注入成功」或自动回退 API 直嗅）

## 第 4 步：收文件

- 列表区自动出现新记录，状态依次：等待 → 下载中 xx% → 解密中 → **已完成 ✓**
- 双击已完成行 = 直接播放；或点 **打开文件夹** 到 `downloads/` 目录拿 mp4
- 文件名格式：`标题_MMDD_HHMMSS.mp4`

## 第 4.5 步：列表上限与授权码（拉整个视频号时必看）

界面「列表上限」显示当前档位（轻量版 500 条 / 标准版 1000 条 / 专业版 2000 条 /
旗舰版 2 万条），右侧是「🔑 授权管理」按钮。

- **满档就停**：列表填满档位后，新捕获的视频**不再加载**（已有记录一条不动、
  不会消失），日志提示「列表已满」，状态栏显示「（已满·未加载 N 条）」，
  「⚡ 批量拉取」会自动停止。
- **填满后想继续拉，两个办法**：
  ① **删记录**：清空已完成 / 删除部分记录，列表低于上限就立即恢复加载
     （小套餐用户勤删记录即可长期使用）；
  ② **升级档位**：找发布方发更高档的授权码。
- **想一次拉完整个视频号**（几百上千条）：先拿到「专业版」或「旗舰版」的
  授权码 → 点「🔑 授权管理」→ 粘进输入框 → 点「激活」（或「📋 粘贴并激活」）
  → **立即生效、无需重启** → 再批量拉取。
- **弹窗还能做**：查看当前档位/授权状态/当前授权码全码；「🗑 清除授权」
  回落到默认档（售后场景）。
- 授权码会记住（config.json），重启仍生效；换电脑需重新输入（不绑定设备）。
- 授权码无效/过期时回落到默认档：**只影响还能不能继续加载新视频，
  已下载的 MP4 与列表里已有记录都不受影响。**

### 授权码怎么用（手把手）

授权码形如 `SPHDL-0410-0WRK-MS6V-XA9S-8JDK-47S4`（35 字符，去掉横杠 29 位），
由发布方通过微信/QQ 发来，**一个码对应一个档位**。

1. 找「列表上限」行 → 点右边的 **「🔑 授权管理」** 按钮
2. 弹窗里找到「更换授权码」下的输入框
3. 粘入授权码（推荐直接点 **「📋 粘贴并激活」** 一键完成）
4. 点 **「激活」** → 提示「授权成功」即完成
5. **★ 无需重启，立即生效**：档位显示、授权状态、状态栏同步更新

- 换码/升级：重复上面步骤即可（同样不用重启）；升级后若原本已满档，
  会立刻恢复加载新视频
- 降级：超出新档位的旧记录被裁掉，但**磁盘上已下载的视频文件不删**
- 排错：提示无效时，检查是否整串复制完整（含 `SPHDL-`）、
  是否把字母 `O` 打成数字 `0`、中间是否混入空格或换行

### 电脑配置要求（按档位）

| 档位 | 内存 | 列表占用 | 说明 |
|---|---|---|---|
| 轻量版 500 条 | 4 GB | ~1 MB | 任意近十年电脑可跑 |
| 标准版 1000 条 | 4 GB | ~1 MB | 任意近十年电脑可跑 |
| 专业版 2000 条 | 8 GB | ~2 MB | 近五年主流电脑 |
| 旗舰版 2 万条 | 8 GB 起 | ~13 MB | 近五年主流电脑 |

- 系统：Windows 10 / 11（64 位）
- "列表占用"仅指记录清单；**视频文件另计**，请预留足够磁盘空间
- 实际内存以「微信 + 浏览器 + 本工具」同时运行计；列表条数越多，
  启动与「点表头排序」越慢（2 万条约 2 秒，属正常）

## 第 5 步：收尾

点 **■ 停止嗅探**（恢复系统代理）→ 关窗口（列表和设置会自动保存，下次还在）。

## 常见问题（排错表）

| 现象 | 原因 | 处理 |
|---|---|---|
| 播放视频但列表不动、日志大量 SSL 错误 | CA 证书没装/没装对 | 重做第 0 步；确认装到了「受信任的根证书颁发机构」 |
| 端口 8899 被占用 | 上次没退干净，或别的服务占了 | 换端口（如 8898）再启动；或在任务管理器结束残留 python |
| 下载失败：链接可能已过期 | 视频号 CDN 链接有效期短 | 点 **重试** 前先回微信重新播放一次该视频（拿新链接），再重试 |
| 解密失败（key 与 url 不匹配） | 抓到的 url 和 decode_key 不是同一次响应 | 同上：重新播放视频让它重新捕获 |
| 停止后网页打不开 | 系统代理没恢复成功 | 设置→网络和 Internet→代理→关掉"使用代理服务器" |
| 微信里视频能播但抓不到 | 微信版本更新导致注入点失效 | 看日志：有「未找到 JS 注入点」说明已自动回退 API 直嗅；若两种都失败，把日志发我 |
| 播放中日志出现「⚠️ 视频在播放，但 90 秒以上没有收到视频号页面的钩子数据」/ 状态栏「钩子: X分钟前 ⚠」 | 视频号页面被 webview 重载/回收，钩子丢失（v1.2.1 起会明确提示） | 返回视频号页面重新进入；或重启微信后再播放；或重启嗅探引擎后重新打开页面 |
| 长时间连续播放一段时间后不再捕获（无警告） | 旧版本事件循环拥塞导致的静默停摆 | 升级 v1.2.1+（已修）；旧版本只能重启引擎恢复 |

## 手动模式（不装代理/不嗅探）

已有 API 响应 JSON（TikHub 或抓包）时：
```
sphdl\..\.venv\Scripts\python main.py --paste response.json
```
只有加密 mp4 + key 时（零依赖解密）：
```
python -c "from sphdl.decryptor import decrypt_file; print(decrypt_file('加密.mp4','2136343393'))"
```
